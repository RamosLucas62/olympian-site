Política de Privacidade

Última atualização: julho de 2026

1. Quem somos

A Olympian é uma plataforma de disparos em massa via WhatsApp API Oficial da Meta. Nossa missão é conectar negócios locais de delivery com seus clientes de forma segura e eficiente. Esta Política descreve como coletamos, usamos e protegemos suas informações.

2. Dados que coletamos

Ao preencher nosso formulário de contato ou utilizar nossos serviços, podemos coletar:

  • Dados de identificação: nome completo e nome da empresa.
  • Dados de contato: número de WhatsApp com DDD.
  • Dados de uso: informações sobre como você interage com nosso site (via Google Tag Manager/Analytics).
  • Listas de contatos: bases de clientes que você nos envia para realização dos disparos.

3. Como usamos seus dados

Utilizamos seus dados exclusivamente para:

  • Entrar em contato via WhatsApp para apresentar sua simulação de disparo;
  • Executar os disparos contratados para sua base de clientes;
  • Melhorar a experiência do nosso site e serviços;
  • Cumprir obrigações legais e regulatórias.

Não vendemos, compartilhamos ou alugamos seus dados para terceiros.

4. Base legal para tratamento (LGPD)

O tratamento dos seus dados é fundamentado nas seguintes bases legais previstas na Lei Geral de Proteção de Dados (Lei nº 13.709/2018):

  • Consentimento: ao preencher o formulário, você consente com o recebimento do nosso contato;
  • Execução de contrato: para prestação dos serviços contratados;
  • Legítimo interesse: para melhorias no site e comunicação comercial relevante.

5. Retenção de dados

Seus dados são mantidos pelo tempo necessário para a prestação dos serviços ou pelo prazo exigido por lei. Listas de contatos enviadas para disparo são excluídas após a conclusão de cada campanha, salvo se você solicitar armazenamento para uso futuro.

6. Compartilhamento com terceiros

Podemos compartilhar dados apenas com:

  • Meta (Facebook/WhatsApp): necessário para execução dos disparos via API Oficial;
  • Ferramentas de análise: Google Analytics (dados agregados e anonimizados);
  • Autoridades competentes: quando exigido por lei ou ordem judicial.

7. Seus direitos

Conforme a LGPD, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados;
  • Acessar os dados que temos sobre você;
  • Corrigir dados incompletos ou desatualizados;
  • Solicitar a eliminação dos seus dados;
  • Revogar o consentimento a qualquer momento.

Para exercer seus direitos, entre em contato pelo e-mail: ramos.lucas@aiolympian.com

8. Cookies e rastreamento

Utilizamos o Google Tag Manager para gerenciar tags de análise e marketing. Isso pode incluir cookies que coletam dados sobre sua navegação de forma agregada. Você pode desativar cookies nas configurações do seu navegador.

9. Segurança

Adotamos medidas técnicas e organizacionais para proteger seus dados contra acesso não autorizado, perda ou divulgação indevida. Todos os dados são transmitidos via conexão segura (HTTPS).

10. Alterações nesta política

Podemos atualizar esta Política periodicamente. A data de última atualização será sempre indicada no topo desta página. Recomendamos revisão periódica.
